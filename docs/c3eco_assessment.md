# C3-ECO assessment contract

PR90's consolidated implementation is documented in [C3-ECO eligibility, scoring, claims and eco-regression assessment](c3eco_certification_assessment.md).

The current native command is `shorthand_c3eco_assess <candidate-directory> <assessment-output.json> [report.md]`. It replaces the earlier draft scorecard CLI before PR90 is merged. See the [integration checkpoint](pr90_integration_checkpoint.md) for the comparison and retained behavior.
