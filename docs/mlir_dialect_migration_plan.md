# ShortHand MLIR dialect migration

PR92 replaces the source-only scaffold with `shorthand.mlir.v1`, generated by
LLVM/MLIR 18 TableGen. Operations retain the names `shorthand.model`,
`shorthand.tensor`, `shorthand.infer`, `shorthand.greenai_contract`, and
`shorthand.greenai_measure`. The old string shape/input/output fields become
ranked tensor signatures and SSA values. Model/contract references become symbols.
Backend and evidence policy become generated attributes. Initialized tensor data
is explicit. Quality guardrails and budgets are preserved as required metadata.

The previous scaffold was never built or published as an MLIR interface. The
new checked example defines the first executable dialect contract. The language
beta-0.7 grammar, existing runtime ABI and direct LLVM compiler path are preserved.
See [the generated dialect contract](../mlir/README.md).

PR93 owns source-alias normalization, SemanticIR conversion, canonicalization,
LLVM lowering, composite execution and runtime hooks. Future RAG retrieval and
model routing require separately specified semantics and qualification. A
registered dialect is not a production compiler pipeline or energy comparison.
