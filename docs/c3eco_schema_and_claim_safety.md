# C3-ECO schema and claim-safety gate

## Purpose

ShortHand currently emits C3-ECO-aligned evidence as candidate artifacts. These artifacts are useful for review, but they must not be interpreted as official certification.

This gate adds a lightweight, dependency-free validation layer for the candidate evidence bundle. It is intentionally conservative and can run in the existing CI image without `jq`, Python packages, or external JSON schema validators.

## Validated artifacts

The bundle generated by `scripts/generate_certification_bundle.sh` must contain:

- `candidate_report.json`
- `candidate_check.json`
- `carbon_workbook.csv`
- `manifest.json`
- `README.md`
- `candidate_report.schema.json`
- `candidate_check.schema.json`
- `bundle_manifest.schema.json`

The schema files live under `schemas/c3eco/` and describe the required shape of the candidate artifacts. Until a full JSON Schema validator is added to CI, `scripts/check_c3eco_claims_and_schema.sh` performs deterministic structural checks with POSIX shell and `grep`.

## Claim-safety rules

Generated artifacts must retain these boundaries:

- `official_certification_granted` must be `false`.
- `report_status` must remain `candidate_assessment_only`.
- The bundle manifest must use `claim_status: candidate_evidence_only`.
- Candidate reports must include blocked certification items.
- Candidate reports must include explicit disclaimer text.
- Offsets and avoided impact must not reduce the base footprint.
- The generated bundle must not claim that a product is C3-ECO Certified.

## Why this matters

This keeps the project commercially useful while avoiding overclaiming. The compiler can produce evidence for future auditor review, but certification still requires external authority review and sign-off.

## Remaining work

Future PRs should add:

- a real JSON Schema validator when dependency policy allows it,
- versioned schema migration rules,
- Markdown/PDF public report generation,
- eco-regression thresholds,
- auditor handoff metadata,
- signed release provenance for generated evidence bundles.
